# Maze 2: спуск в подземелье Минотавра

Продолжение бродилки из ДЗ 3. Теперь это не один лабиринт, а подземелье из нескольких этажей.
На каждом этаже нужно найти ключ от лестницы, а на последнем этаже выход стережёт Минотавр.

```
python main.py                # 3 этажа, первый 6 x 9
python main.py 8 12           # свой размер первого этажа
python main.py --floors 5     # больше этажей
python main.py --seed 42      # один и тот же мир
python main.py --load         # продолжить сохранённую игру
python -m unittest tests.py   # проверки
```

Нужен только Python, сторонних библиотек нет.

## Что нового по сравнению с ДЗ 3

- **Этажи.** Каждый следующий этаж больше и злее, на нём другие монстры и лут получше.
- **Монстры ходят.** Учуяв вас за 5 шагов, они идут навстречу, остальные бродят. Если монстр зайдёт к вам в комнату, бой начнётся сам.
- **Пошаговый бой.** В каждом раунде можно бить, пить зелье, кинуть огненный свиток или попробовать сбежать. Бывают криты.
- **Свет.** Без факела видно на 2 комнаты вокруг, с факелом на 4. Факел догорает, новый можно найти или скрафтить.
- **Экипировка.** Оружие и броня с прочностью: оружие тупится и ломается, броня поглощает урон.
- **Опыт и уровни.** За уровень дают +15 к максимуму hp и +2 к урону.
- **Яд.** Его дают пауки, ядовитые ловушки и протухшие фонтаны. Лечится противоядием.
- **Торговец (&).** Это безопасная комната, куда монстры не заходят. У него можно продать хабар и купить снаряжение.
- **Фонтаны (≈).** Глоток из фонтана может вылечить, усилить, отравить, подарить золото или куда-нибудь телепортировать.
- **Мимики.** Иногда сундук оказывается монстром.
- **Крафт.** 8 рецептов: факел, копьё, костяной доспех, бомба, зелье ярости, рубиновый посох и т.д.
- **Бомбы.** Командой `bomb w/a/s/d` можно проломить стену и срезать путь.
- **Свитки.** Есть свиток карты, свиток телепорта и свиток огня.
- **Сохранение** (`save`, затем `--load`). Если персонаж погиб, сохранение удаляется.
- **Рекорды и достижения.** Десятка лучших хранится в `records.json`, а ачивки выдаются за Минотавра, крафт, взрывы и т.д.

## Файлы

| Файл | Что там |
|---|---|
| `main.py` | запуск, аргументы, таблица рекордов |
| `game.py` | игрок, ходы, бой, торговля, крафт, сохранение |
| `world.py` | генерация лабиринта и этажей, комнаты, бестиарий |
| `items.py` | предметы, лут, рецепты, класс `Inventory` |
| `ui.py` | цвета и ввод-вывод |
| `tests.py` | проверки инвентаря, генерации и случайные прогоны игры |

## Операции со списками

Всё с доски из ДЗ 3 осталось в классе `Inventory` (`items.py`): `append` / `extend`, `remove` / `pop`, `sort` / `reverse`, `in` / `index`, срезы.
Добавилось ещё несколько:

- Крафт копирует список имён (`copy`) и вычёркивает из копии ингредиенты через `remove`, чтобы проверить, хватает ли всего.
- Таблица рекордов сортируется по очкам, и срезом `[:10]` в ней остаются лучшие.
- `zip(*pairs)` распаковывает таблицу лута, `itertools.islice` раздаёт клетки при генерации этажа, а `Counter` считает одинаковые предметы.
