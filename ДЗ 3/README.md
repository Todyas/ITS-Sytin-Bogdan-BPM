# ДЗ 3. Бродилка по лабиринту с инвентарём

```
python maze.py              # лабиринт 7 x 10
python maze.py 10 15        # свой размер n x m
python maze.py --seed 42    # один и тот же лабиринт каждый раз
```

Нужен только Python 3.8+, сторонних библиотек нет.

Игрок появляется в углу случайного лабиринта с `hp = 100`, кинжалом и малым зельем.
Видно только то, где уже побывал. Цель: найти **золотой ключ** (`K`) и выйти через дверь `E`.

| Комната | Что происходит |
|---|---|
| пустая | ничего, иногда на полу лежат вещи (`*`) |
| `$` сундук | 2–4 случайных предмета сразу в рюкзак (что не влезло, остаётся на полу) |
| `M` монстр | драться или бежать; оружие в бою теряет прочность и может сломаться |
| ловушка | невидима, пока не наступишь: отнимает hp и может вытряхнуть вещь из рюкзака |
| `K` ключ | без него дверь не откроется |
| `O` портал | порталы связаны попарно и перебрасывают в другой конец лабиринта |

Рюкзак ограничен по весу (25). Точильный камень усиливает оружие, перо феникса спасает от смерти один раз.

## Где задания с доски

| Задание | Методы | Где в коде |
|---|---|---|
| 1. Собирать предметы | `append`, `extend` | `Inventory.add`, `Inventory.add_many` (сундук, команда `t`) |
| 2. Выбрасывать предметы | `remove`, `pop` | `drop имя`, `drop N` / `drop`, ловушка-воришка |
| 3. Сортировать инвентарь | `sort`, `reverse` | `sort цена -`, `rev` |
| 4. Искать ключевой предмет | `index`, `in` | `find`, проверка ключа у двери |
| 5*. Копировать и менять списки | `copy`, срезы | `copy` (поверхностная и глубокая копия), `top`, пары порталов `[::2]`, `[1::2]` |
| 6**. Итераторы коллекций | `__iter__`, генераторы, `iter`/`next`, `zip`, `enumerate`, `groupby` | `Inventory`, `Maze`, `populate`, команда `g` |

Изменение свойств предметов: прочность оружия падает в бою, точильный камень меняет урон и прочность.
